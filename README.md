# N9TTA — сайт-портфолио

Сайт-портфолио арт-директора Матвея Новика (N9TTA) в стиле medieval occult revival: главная для творцов и набор коммерческих страниц под разные архетипы заказчиков.
Живёт на [n9tta.art](https://n9tta.art), деплоится на Vercel автоматически при пуше в `master`.

## Стек

- **Next.js 16** (App Router) + TypeScript
- **Tailwind CSS v4** — токены через `@theme` в `app/globals.css`
- **Framer Motion** — прелоадер, флип карточек, каскадное появление
- **GSAP + ScrollTrigger** — реакция на velocity скролла, дорисовка орнаментов
- **Lenis** — плавный скролл

Сборка не требует настроек в дашборде Vercel: фреймворк задан в `vercel.json`.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000. Продакшн-сборка — `npm run build`, линтер — `npm run lint`.

## Как устроен сайт

Сайт — конструктор. Каждая страница описана в `content/` как список блоков,
порядок в массиве `sections` = порядок на странице.

```
content/
  profile.ts          ядро личности: имя, контакты, блок «Кто я» на каждом языке
  cases.ts            общий архив кейсов (теги + переводы в поле i18n)
  home.ts             главная — для творцов, крючок на коллабу
  offers/
    index.ts          реестр коммерческих страниц
    _template.ts      витрина всех 15 блоков — копировать для новой страницы
    brand.ts          /for/brand   — предприниматели, брендинг
    music.ts          /for/music   — артисты и лейблы
    studio.ts         /for/studio  — студии и агентства, на английском
  types.ts            описание всех блоков и их полей
  ui.ts               служебные надписи на каждом языке
components/
  blocks/             по компоненту на блок + общая оболочка Section
  page/               PageRenderer (реестр блоков), Nav, Footer, контекст языка
app/
  page.tsx            главная
  for/[slug]/page.tsx коммерческие страницы
```

### Править тексты

Все места, которые ждут текста, помечены `[впиши]` (на английских страницах `[write]`) — ищи по проекту.

### Менять композицию

- **Переставить** — переместить объект в массиве `sections`.
- **Скрыть** — `hidden: true`.
- **В меню** — поле `nav: 'Подпись'`; меню собирается само, в порядке блоков.
- **Подпись над заголовком** — `label`; по умолчанию сквозная нумерация `N° 01…`.
- **Кейсы** — в блоке `works` либо `cases: ['case-gazgolder', …]` (точный список и порядок), либо `tags: ['music']`.
- **Блок «Кто я»** берётся из `profile.ts` и переопределяется на месте: `{ ...PERSONA.ru, heading: 'Почему я' }`.

Блоки: `hero` (варианты `emblem` и `statement`), `marquee`, `manifesto`, `works`, `persona`,
`exchange`, `ideas`, `pain`, `services`, `process`, `proof`, `stats`, `faq`, `cta`, `text`.
Поля каждого описаны в `content/types.ts` — редактор подсказывает их автоматически.

### Новая коммерческая страница

1. Скопировать `content/offers/_template.ts` в `content/offers/<slug>.ts`.
2. Поменять `slug`, `lang`, `title`, `description` и тексты, удалить лишние блоки.
3. Добавить импорт в `content/offers/index.ts`.

Страница появится по адресу `/for/<slug>`. В поиск не попадает, пока не указано `index: true`, — раздаётся по прямой ссылке.
Несуществующий slug отдаёт 404. Витрина всех блоков открывается только локально: `npm run dev` → `/for/_template`.

### Другой язык

Английский уже есть. Новый язык: добавить код в `Lang` (`content/types.ts`), словарь в `content/ui.ts`,
блок в `PERSONA` и `location` в `profile.ts`. TypeScript подсветит всё, что осталось заполнить.
Переводы кейсов — в поле `i18n` кейса; всё непереведённое берётся из русского.

### Картинки

- **Обложки кейсов** — `public/assets/card-01…06`. Пропорция 3:4, ширина ~1200px, webp. Путь — поле `cover` у кейса.
- **Портрет** — `public/assets/portrait.svg`, пропорция 4:5. Путь — `portrait.src` в `profile.ts`.

Для `.svg` автоматически включается `unoptimized` — оптимизатор Next не обрабатывает SVG.

## Дизайн-токены

| Токен | Значение | Применение |
|---|---|---|
| `--color-ink` | `#0D0D0D` | основной фон |
| `--color-charcoal` | `#1A1A1A` | приподнятые поверхности: карточки, модалка |
| `--color-bone` | `#E8E2D0` | текст, линии, гравюры |
| `--color-blood` | `#A32626` | акценты, hover, печати |
| `--color-gold` | `#8A7440` | тонкие орнаменты, рамки |

Тема одна — тёмная, в эстетике gothic occult revival. Светлой версии нет.

Зерно работает в режиме `mix-blend-mode: screen`: на тёмном фоне `multiply` не даёт ничего, зерно должно осветлять.

### Шрифты

**Pirata One** (блэклеттер) не поддерживает кириллицу, поэтому используется только на латинице: вордмарк, `ART DIRECTOR`, навигация, бегущая строка. Все русские заголовки набраны антиквой **Cormorant Garamond**. Тексты — **IBM Plex Sans**, лейблы и нумерация — **IBM Plex Mono** (обе с кириллицей).

Если менять шрифты — проверяйте наличие кириллического subset, иначе русский текст провалится в системный fallback.

## Доступность и анимации

- При `prefers-reduced-motion` отключаются Lenis, GSAP, бегущая строка, вращение кольца и прелоадер.
- Кастомный курсор, 3D-tilt, magnetic и scramble включаются только при точном указателе и ширине от 768px (`lib/motion.ts`).
- Прелоадер гарантированно уходит по таймеру: в фоновой вкладке `requestAnimationFrame` не тикает, и без страховки он бы висел до фокуса вкладки.
