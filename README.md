# N9TTA — сайт-портфолио

Сайт Матвея Новика (N9TTA). Главная — не продающая: знакомство, что я считаю искусством, зачем нам коллаборации.
Коммерческие страницы под разные типы заказчиков живут по прямым ссылкам `/for/<slug>`.
Деплоится на Vercel автоматически при пуше в `master`.

## Стек

- **Next.js 16** (App Router) + TypeScript
- **Tailwind CSS v4** — токены через `@theme` в `app/globals.css`
- **Framer Motion** — только выезд карточки кейса

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000. Продакшн-сборка — `npm run build`, линтер — `npm run lint`.

## Как устроен сайт

Сайт — конструктор. Каждая страница описана в `content/` как список блоков,
порядок в массиве `sections` = порядок на странице.

```
content/
  profile.ts          ядро личности: имя, контакты, блок «Кто я» на каждом языке
  cases.ts            общий архив кейсов (теги + переводы в поле i18n)
  home.ts             главная: знакомство, искусство, коллаборации
  offers/
    index.ts          реестр коммерческих страниц
    shared.ts         общие куски: процесс, FAQ, «Почему N9TTA», флагманский формат, контакты
    _template.ts      витрина всех 16 блоков — копировать для новой страницы
    launch.ts         /for/launch     — стартапы перед запуском
    music.ts          /for/music      — артисты и лейблы
    streetwear.ts     /for/streetwear
    gaming.ts         /for/gaming
    culture.ts        /for/culture    — выставки, институции, книги
    tech.ts           /for/tech       — IT-продукты
    festival.ts       /for/festival
    media.ts          /for/media
    product.ts        /for/product    — независимые продуктовые бренды
  types.ts            описание всех блоков и их полей
  ui.ts               служебные надписи на каждом языке
components/
  blocks/             по компоненту на блок + общая оболочка Section
  page/               PageRenderer (реестр блоков), Nav, Footer, контекст языка
app/
  page.tsx            главная
  for/[slug]/page.tsx коммерческие страницы
```

### Править тексты

Все места, которые ждут текста, помечены `[впиши]` (на английских страницах `[write]`) — ищи по проекту.

### Имена клиентов

Список в `content/profile.ts` → `CLIENTS`. На сайт попадают только имена с `cleared: true` —
включай после проверки разрешений, NDA и формулировки своей роли. Отзывы — только реальные и с согласия.

### Менять композицию

- **Переставить** — переместить объект в массиве `sections`.
- **Скрыть** — `hidden: true`.
- **В меню** — поле `nav: 'Подпись'`; меню собирается само, в порядке блоков.
- **Подпись над заголовком** — `label`; по умолчанию сквозная нумерация `N° 01…`.
- **Кейсы** — в блоке `works` либо `cases: ['case-gazgolder', …]` (точный список и порядок), либо `tags: ['music']`.
- **Блок «Кто я»** берётся из `profile.ts` и переопределяется на месте: `{ ...PERSONA.ru, heading: 'Почему я' }`.

Блоки: `intro`, `hero`, `marquee`, `manifesto`, `collab`, `works`, `persona`, `ideas`, `pain`, `services`, `process`, `proof`, `stats`, `faq`, `cta`, `text`.
Поля каждого описаны в `content/types.ts` — редактор подсказывает их автоматически.

### Новая коммерческая страница

1. Скопировать `content/offers/_template.ts` в `content/offers/<slug>.ts`.
2. Поменять `slug`, `lang`, `title`, `description` и тексты, удалить лишние блоки.
3. Добавить импорт в `content/offers/index.ts`.

Страница появится по адресу `/for/<slug>`. В поиск не попадает, пока не указано `index: true`, — раздаётся по прямой ссылке.
Несуществующий slug отдаёт 404. Витрина всех блоков открывается только локально: `npm run dev` → `/for/_template`.

### Другой язык

Каждая страница говорит своим тоном — это задаётся текстами. Английский интерфейс уже заложен, но локализация — это отдельные тексты под аудиторию, а не перевод. Новый язык: добавить код в `Lang` (`content/types.ts`), словарь в `content/ui.ts`,
блок в `PERSONA` и `location` в `profile.ts`. TypeScript подсветит всё, что осталось заполнить.
Переводы кейсов — в поле `i18n` кейса; всё непереведённое берётся из русского.

### Картинки

- **Обложки кейсов** — `public/assets/card-01…06`. Пропорция 3:4, ширина ~1200px, webp. Путь — поле `cover` у кейса.
- **Портрет** — положить фото в `public/assets/`, пропорция 4:5, и раскомментировать `portrait` в `profile.ts`.

Для `.svg` автоматически включается `unoptimized` — оптимизатор Next не обрабатывает SVG.

## Дизайн

Самиздат и типографический максимализм: бумага, чёрная краска, один сигнальный цвет, огромный набор,
россыпи символов и асимметричная сетка.

| Токен | Значение | Применение |
|---|---|---|
| `--color-paper` | `#ECE8DF` | фон |
| `--color-ink` | `#121110` | текст, линии, чёрные плашки |
| `--color-signal` | `#E0321C` | символы, главная кнопка, выделение |
| `--color-ash` | `#6D6961` | подписи |

Шрифты (все с кириллицей): **Dela Gothic One** — заголовки капсом, **Spectral** — тексты, **IBM Plex Mono** — подписи и символы.

- **Асимметрия** заложена в `components/blocks/Section.tsx`: у чётных блоков поле с номером и символом слева, у нечётных справа.
  Поэтому блоки можно переставлять как угодно — страница всё равно «качается».
- **Символы** — набор в `components/ui/glyphs.ts`. `GlyphField` рассыпает их детерминированно по `seed`,
  заголовки при появлении «собираются» из них (`ScrambleHeading`, только на десктопе и без reduced motion).
